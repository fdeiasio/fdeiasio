## Selected work

### [ml2-stereo-pipeline](https://github.com/fdeiasio/ml2-stereo-pipeline)

Stereo depth and 6-DoF object pose from Magic Leap 2 world cameras. Calibration, rectification,
block-matching disparity, point-cloud reconstruction, and ICP registration of a known mesh.

`Python` `OpenCV` `Open3D` `stereo vision` `depth estimation` `ICP` `point clouds`

### [ml2-camera-streamer](https://github.com/fdeiasio/ml2-camera-streamer)

The device side of the same system: a Unity application that streams all three world cameras over
TCP to a host workstation at 30 fps, so the vision stack runs off the glasses.

`Unity` `C#` `TCP` `Magic Leap 2` `augmented reality`
